# Контрольные тесты — инженерный калькулятор (ТЗ 2.2.0)

**Назначение:** приёмка логики расчётов до и после реализации.  
**Обозначения:** «Модель-U» — упрощённая модель ТЗ 2.2.0 (ρ, cos φ=1, фиксированные таблицы режима). «Норма» — полный проектный расчёт (вне объёма приложения).

---

## 1. Обязательные тесты приёмки (из задания)

### T-A. Кабель на заказ

| Поле | Значение |
|------|----------|
| Участки одной трассы | 12 м (одна строка) |
| Число трасс | 3 |
| Запас | 10% |
| Длина бухты | не задана |

| Проверка | Ожидание |
|----------|----------|
| База | 36 м |
| С запасом | 39,6 м |
| **Итог для заказа (ceil 1 м)** | **40 м** |
| Умножение на 2 (фаза+ноль отдельно) | **запрещено** |
| Прибавление длины бухты к метражу | **запрещено** |

### T-B. Сечение, короткая линия

| Параметр | Значение |
|----------|----------|
| I | 16 А |
| Материал | медь |
| Прокладка | в трубе, 1–2 кабеля |
| L | 30 м |
| U | 220 В, 1 фаза |
| cos φ | 1 (модель-U) |
| Лимит ΔU | 5% (силовая/розеточная, модель-U) |

| Проверка | Ожидание (модель-U) |
|----------|---------------------|
| Iдоп 2,5 мм² | ≥ 16 А |
| ΔU % при 2,5 мм² | ≈ 3,05% |
| **Рекомендуемое S** | **2,5 мм²** |

### T-C. Сечение, длинная линия

Как T-B, **L = 60 м**.

| S | ΔU % (модель-U) | Статус |
|---|-----------------|--------|
| 2,5 | ≈ 6,11% | отклонено по ΔU |
| 4 | ≈ 3,82% | принято |
| **Итог** | | **4 мм²** |

## 2. Дополнительные тесты

### T-3PH. Трёхфазная сеть (модуль ΔU)

| I | L | S | U | Фаза |
|---|----|---|---|------|
| 16 | 30 | 4 | 380 | 3 |

Формула модель-U: ΔU = √3·I·L·ρ/S.  
Ожидание: ΔU% = 100·(√3·16·30·0,0175/4)/380 ≈ **1,16%**.

### T-AL. Алюминий 16 А, в трубе, без длины

Ожидание модель-U (таблица режима «ВВГ в трубе»): **4 мм²** (2,5 мм² Iдоп ≈ 15 А < 16 А).

### T-LIGHT. Освещение

| S помещения | Вт/м² |
|-------------|-------|
| 20 | 15 |

Ожидание: P = 300 Вт; I_ориентир = 300/220 ≈ 1,36 А; **не** выводить ΔU.

### T-LED-DC. Лента 12 В

| L ленты | Вт/м | U |
|---------|------|---|
| 5 | 14,4 | 12 |

P = 72 Вт; I_load = 6 А; БП с k=1,2: P_БП ≥ 86,4 Вт.

### T-LED-DROP. DC линия 15 м, 1,5 мм², I=6 А

ΔU = 2·6·15·0,0175/1,5 = 1,05 В → 8,75% при U=12 В → **вне лимита 3%** для LED.

### T-BRK. Автомат 3 кВт, 220 В, 1ф, cos φ=1

I ≈ 13,64 А; I_design = 17,05 А → автомат **20 А**; **статус:** защита кабеля не подтверждена без ввода S.

### T-ORDER-EDGE. Граничные случаи

| Кейс | Ввод | Ожидание |
|------|------|----------|
| Пустые длины | — | ошибка валидации, нет числа |
| Трассы 0 | — | ошибка |
| Запас пустой | 0% | |
| Запас 100% | | отклонить или cap по ТЗ (макс. 50% — настройка) |
| Бухта 0 | | игнорировать бухты |
| Бухта 100, итог 40 м | | 1 бухта, остаток 60 м **не** прибавляется к заказу |

### T-NO-SECTION. Нет подходящего сечения

I = 200 А, таблица режима заканчивается 95 мм² — **сообщение «вне диапазона»**, не выдавать 95 мм² как «прошедшее», если I > Iдоп.

## 3. Критерии статуса теста

| Статус | Условие |
|--------|---------|
| PASS | Все проверки модуля для модели-U |
| PASS-NORM | Только при ручной верификации инженером по ПУЭ/СП |
| FAIL | Арифметика или логика не совпадает |
| N/A | Модуль не реализует заявленную полноту |
