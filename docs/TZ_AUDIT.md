## Этап 1. Перечень ошибок по критичности

### Критические (безопасность / ввод в заблуждение)

| ID | Модуль | Проблема | Где проявляется |

## Этап 2. Контрольные примеры (арифметика)

### Тест A — длина кабеля

| Шаг | Значение |
|-----|----------|
| Длина одной трассы | 12 м |
| Число трасс | 3 |
| Запас | 10% |
| База | 12 × 3 = 36 м |
| С запасом | 36 × 1,1 = **39,6 м** |
| По ТЗ приёмки (округление вверх до 1 м) | **40 м** |
| Текущее приложение v1.1.9 | **39,6 м** (несоответствие приёмке) |

Запрет: не умножать на 2 «туда-обратно» для одного кабеля; не прибавлять длину бухты к метражу.

### Тест B — сечение (упрощённая модель ΔU, cos φ = 1, ρ меди 0,0175 Ом·мм²/м)

Вход: I = 16 А; медь; в трубе; L = 30 м; U = 220 В; 1 фаза.

| Критерий | Расчёт | Итог |
|----------|--------|------|
| Допустимый ток (таблица приложения, 2,5 мм² в трубе) | Iдоп ≈ 21 А ≥ 16 А | 2,5 мм² проходит |
| Практический минимум приложения | ≥16 А → 2,5 мм² | 2,5 мм² |
| ΔU = 2·L·I·ρ/S | 2×30×16×0,0175/2,5 = 6,72 В | |
| ΔU % | 6,72/220×100 ≈ **3,05%** | ≤ 5% (модель приложения) |
| **Итог модели приложения** | | **2,5 мм²** |

### Тест C — длина 60 м (остальное как B)

| S, мм² | ΔU % (упрощённая формула) |
|--------|---------------------------|
| 2,5 | ≈ **6,11%** — не проходит критерий 5% |
| 4 | ≈ **3,82%** — проходит |
| Iдоп 4 мм² (таблица приложения) | ≈ 27 А ≥ 16 А |

**Итог модели приложения:** **4 мм²**.

Полная модель с cos φ < 1 и реактивностью может дать иной S — **требует проверки** при расширении ТЗ.

## Повторная проверка на противоречия (этап 6)

- Тест B/C согласованы с упрощённой формулой ΔU и таблицей токов **модели 2.2.0**, не с полным проектом ПУЭ.
- Тест A требует ceil метража — не противоречит модулю бухт (бухты считаются от уже округлённого метража).
- Режим «предварительный подбор» явно исключает заявление о нормативной полноте — согласовано с дисклеймером.
