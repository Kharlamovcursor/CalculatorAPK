# Удобная настройка: HDLabs ЭлектроСмета (Windows)

Инструкция для повседневной работы: правки кода → сборка APK → отправка мастерам → обновления через GitHub.

---

## Что выбрать (коротко)

| Вариант | Кому подходит |
|--------|----------------|
| **Android Studio + Cursor** (рекомендуется) | Правите код в Cursor, собираете и ставите APK в Studio — быстро и без возни с SDK вручную |
| Только Android Studio | Всё в одной программе, если не нужен Cursor |
| Только SDK + терминал | Не рекомендуется для первого раза |

**Рекомендация:** установить **Android Studio**, проект держать в `D:\Projects\CalculatorAPK`, код править в **Cursor**, сборку и установку на телефон делать в **Studio**.

---

## Часть 1. Один раз: установка (30–60 минут)

### 1.1 Android Studio

1. Скачайте: https://developer.android.com/studio  
2. Установите с настройками по умолчанию (вместе с ними ставится **JDK** и загрузчик **Android SDK**).  
3. При первом запуске мастер предложит **Standard** — соглашайтесь.

### 1.2 Компоненты SDK

**File → Settings → Languages & Frameworks → Android SDK**

Вкладка **SDK Platforms** — отметьте:

- Android 15.0 (API 35) — для сборки проекта  
- Android 9.0 (API 28) — минимальная версия приложения (по желанию для эмулятора)

Вкладка **SDK Tools** — отметьте:

- Android SDK Build-Tools  
- Android SDK Platform-Tools  
- Android Emulator (если хотите тест без телефона)

Нажмите **Apply** и дождитесь загрузки.

### 1.3 Открыть проект

1. **File → Open** → `D:\Projects\CalculatorAPK`  
2. Дождитесь **Gradle Sync** (строка внизу, без красных ошибок).  
3. Если Studio просит обновить Gradle/AGP — можно согласиться.

### 1.4 Проверка

Меню **Build → Make Project** (Ctrl+F9). Должно завершиться успешно.

## Часть 2. Как работать каждый день (удобный цикл)

```
Cursor: правки кода → сохранить файлы
        ↓
Android Studio: Sync (иконка слона) → Run ▶ или Build APK
        ↓
Телефон или Telegram: установка / отправка мастеру
```

### В Cursor

- Открывайте ту же папку `D:\Projects\CalculatorAPK`.  
- Меняйте Kotlin, прайс, тексты — **сохраняйте файлы** (Ctrl+S).  
- Studio сама подхватит изменения (иногда нажмите **Sync Project with Gradle Files**).

### В Android Studio

| Задача | Действие |
|--------|----------|
| Запуск на телефоне | Подключить USB → **Run ▶** |
| APK «для себя» | **Build → Build APK(s)** → debug |
| APK «для мастеров» | Подписанный **release** (см. часть 4) |

**Не обязательно** держать Studio открытой постоянно — только когда нужна сборка или отладка.

## Часть 3. Телефон: самый удобный способ теста

### Вариант A — USB (надёжнее)

1. На телефоне: **Настройки → О телефоне** → 7 раз «Номер сборки» → режим разработчика.  
2. **Для разработчиков** → **Отладка по USB** — включить.  
3. Кабель к ПК → в Studio выберите устройство в списке → **Run ▶**.

### Вариант B — без кабеля (после пары раз с USB)

**Для разработчиков → Беспроводная отладка** — спарить с Studio (Android 11+).

### Вариант C — только APK файлом

1. Собрать debug/release APK.  
2. Отправить себе в **Telegram / MAX / «Файлы»**.  
3. Открыть файл → разрешить установку **из этого приложения** → установить.

## Часть 4. Release APK для мастеров (один раз настроить ключ)

### 4.1 Создать ключ подписи

В **Terminal** внизу Android Studio (или PowerShell):

```bat
cd D:\Projects\CalculatorAPK
keytool -genkeypair -v -keystore release.keystore -alias hdlabs -keyalg RSA -keysize 2048 -validity 10000
```

Запомните пароли. Файл `release.keystore` **не коммитьте в Git**.

### 4.2 keystore.properties

Скопируйте `keystore.properties.example` → `keystore.properties`:

```properties
storeFile=release.keystore
storePassword=ВАШ_ПАРОЛЬ
keyAlias=hdlabs
keyPassword=ВАШ_ПАРОЛЬ
```

### 4.3 Сохранить ключ (обязательно)

Скопируйте на флешку / в облако (зашифровано):

- `release.keystore`  
- пароли (менеджер паролей)

**Без этого ключа нельзя выпускать обновления поверх старого APK.**

### 4.4 Собрать release

**Build → Generate Signed App Bundle or APK → APK → release**

Файл: `app\build\outputs\apk\release\app-release.apk`

Переименуйте, например: `HDLabs-Electrosmeta-1.0.0.apk`.

## Часть 5. GitHub — удобная схема обновлений

Два репозитория — меньше путаницы:

| Репозиторий | Содержимое |
|-------------|------------|
| **Приватный** | Исходный код (этот проект) |
| **Публичный** только релизы | Только APK и `checksum.txt`, без паролей и keystore |

### Как выпустить обновление

1. В `app/build.gradle.kts` увеличьте `versionCode` и `versionName`.  
2. Соберите **release APK**.  
3. На GitHub: **Releases → New release**, тег `v1.0.1`, прикрепите APK.  
4. В приложении на телефоне: **Настройки → О приложении** — укажите `owner` и `repo` публичного репозитория.  
5. **Проверить обновления** → скачать → подтвердить установку.

## Часть 6. Резервная копия данных приложения

На телефоне мастера: **Настройки** → **Экспорт** → файл `.hdeb` в облако.

При смене телефона: **Импорт** (сначала покажется состав копии — подтвердить). Пароль не нужен. Старые копии, сделанные с паролем, эта версия не открывает.

## Часть 7. Частые проблемы

| Проблема | Решение |
|----------|---------|
| Gradle Sync failed | **File → Invalidate Caches → Restart**; проверьте интернет при первой загрузке SDK |
| SDK not found | Settings → Android SDK → указать путь, доустановить Platform 35 |
| Телефон не виден | Драйвер USB / другой кабель / отладка по USB |
| «Приложение не установлено» | Другой ключ подписи — удалить старую версию или всегда один keystore |
| Play Protect ругается | Нормально для APK не из магазина — «Установить всё равно» |
