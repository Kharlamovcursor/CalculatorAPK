## 0. Область применения и ограничения

### 0.1. Назначение

Мобильное приложение для **ориентировочных** расчётов при электромонтаже: подбор сечения, ΔU, защиты, LED, метраж кабеля, смета работ. **Не заменяет** проектную документацию, испытания и расчёт токов КЗ.

### 0.2. Классы расчётов

| Класс | Описание |
|-------|----------|
| **Н** | Нормативно ориентированный (со ссылкой на документ; значения — только после верификации инженером) |
| **И** | Инженерное допущение (задаётся в ТЗ, помечается в UI) |
| **П** | Пользовательская настройка |
| **С** | Справочная рекомендация |

### 0.3. Обязательный дисклеймер (все экраны «Расчёты»)

> Расчёт ориентировочный. Упрощённые модели и таблицы могут не совпадать с ПУЭ, СП и ГОСТ. Ответственность за безопасность установки несёт исполнитель и проектировщик.

## 2. Единый формат результата (все модули)

Каждый расчёт выводит блоки (сворачиваемые при нехватке места):

1. **Итог** — одна фраза с числом и единицами.  
2. **Исходные данные** — перечень принятых вводов.  
3. **Метод и формула** — уравнение и режим (полный / упрощённый).  
4. **Подстановка** — численный расчёт.  
5. **Проверки** — таблица критерий / значение / статус (OK / не OK / не проверялось).  
6. **Предупреждения** — ограничения модели.  
7. **Нормативная база** — только подтверждённые ссылки; иначе «Требует проверки».

Не показывать ΔU в модулях, где ΔU не вычисляется.

## 3. Модуль «Сечение кабеля»

### 3.1. Режимы

| Режим | Когда | Предупреждение |
|-------|-------|----------------|
| **Полный** | Заполнены все обязательные поля режима кабеля | — |
| **Предварительный** | Не хватает типа кабеля / жил / температуры | «Предварительный подбор, не для проекта» |

### 3.2. Минимальный набор исходных данных (полный режим — целевой)

| Параметр | Обязательность | Примечание |
|----------|----------------|------------|
| Ток нагрузки I, А | да | фазный для 3ф |
| Материал жилы | да | Cu / Al |
| Способ прокладки | да | см. 3.3 |
| Длина L, м (в одну сторону) | нет* | *для проверки ΔU — да |
| U, В; число фаз | да | 220/1ф, 380/3ф (межфазное) |
| Тип линии (силовая / освещение / двигатель) | да | для лимита ΔU |
| cos φ | при полной модели ΔU | по умолчанию 1 в упрощённой |
| Тип кабеля / число нагруженных жил | полный режим | **Требует проверки** привязки к табл. ПУЭ |
| Температура среды | опционально | коэфф. **Требует проверки** |
| Число кабелей в общей трубе | да (если в трубе) | 1–2 / 3–5 / 6+ — **Требует проверки** ступеней ПУЭ |

### 3.3. Способы прокладки (не смешивать таблицы)

Отдельные таблицы допустимого тока **И** для каждой комбинации (класс **Н**, конкретные табл. — **Требует проверки** инженером по ПУЭ-7 гл. 1.3):

- провода одиночной прокладке (ориентир: табл. 1.3.8 — **Требует проверки**);
- кабели в воздухе (табл. 1.3.6 — **Требует проверки**);
- кабели в трубах/коробах (табл. 1.3.7 — **Требует проверки**);
- иные способы — вне MVP, с пометкой «не реализовано».

**Текущая MVP-модель (И):** две кнопки «в трубе» / «открыто» с одной сжатой таблицей — допустима только в режиме **Предварительный**.

### 3.4. Поправочные коэффициенты

| Условие | Коэфф. (MVP, **И**) | Норматив |
|---------|---------------------|----------|
| 3–4 кабеля в одной трубе | **0,8** к Iдоп | ПУЭ табл. 1.3.11 — **Требует проверки** номера и значения |
| Температура ≠ +25 °C | не в MVP | табл. 1.3.12 — **Требует проверки** |

Запрещено использовать **0,9** как универсальный для группы 3–4 без обоснования.

### 3.5. Падение напряжения

**Упрощённая модель (MVP, cos φ = 1, постоянная ρ):**

- 1 фаза: `ΔU = 2 · L · I · ρ / S`  
- 3 фазы: `ΔU = √3 · L · I · ρ / S`  

ρ: Cu 0,0175 Ом·мм²/м; Al 0,028 Ом·мм²/м (**И**, при 20 °C).

**Применимость:** однородная линия, активная нагрузка, без учёта X — для **предварительной** оценки.

**Полная модель (вне MVP):** учёт cos φ, R и X кабеля — **Требует проверки** методики.

**Лимиты ΔU (% от U)** — не взаимозаменяемы:

| Тип линии | Лимит MVP (**И**, настраиваемый) | Норматив |
|-----------|----------------------------------|----------|
| Силовая / розеточная (быт) | 5% | ПУЭ/СП — **Требует проверки** (часто до 5% суммарно от ввода) |
| Освещение | 3% | **Требует проверки** |
| LED DC от БП | 3% | **И**, от U БП |
| Двигатели | отдельный | **Требует проверки** |

### 3.6. Алгоритм подбора S

1. Выбрать минимальное S из стандартного ряда: 1,5; 2,5; 4; 6; 10; 16; 25; 35; 50; 70; 95 мм².  
2. Проверить Iдоп(S) ≥ I.  
3. Если задан L — проверить ΔU ≤ лимита; при нарушении увеличить S.  
4. Применить минимальные сечения (**И**): Cu силовые ≥ 1,5 мм²; Al ≥ 2,5 мм².  
5. **Практический минимум (И):** для розеточных линий Cu при I ≥ 16 А не снижать ниже 2,5 мм² даже если таблица допускает 1,5 — **помечать в итоге**.  
6. Если ни одно S не проходит — сообщение «Нет решения в диапазоне», **не** выдавать последнее S как безопасное.  
7. Защита от бесконечного цикла: максимум N шагов по ряду (N = размер ряда).

### 3.7. Инженерные допущения MVP (явно)

- 220 и 380 В при одном I без L дают одинаковое S по нагреву.  
- Напряжение не влияет на Iдоп по таблице (верно для таблиц длительного тока).

## 4. Модуль «Ток и автомат»

### 4.1. Формулы

| Сеть | P в кВт | I, А |
|------|---------|------|
| 1ф | P | `I = P·1000 / (U · cos φ)` |
| 3ф | P | `I = P·1000 / (√3 · U · cos φ)` |

P — **активная** мощность, кВт. Если ввод в Вт — пересчёт в ТЗ UI.

### 4.2. cos φ

| cos φ | Поведение |
|-------|-----------|
| Задан пользователем | использовать |
| Неизвестен | cos φ = 1 + предупреждение «завышен риск для реактивной нагрузки» |

### 4.3. Автомат

- Расчётный ток для выбора: `Iр = I · 1,25` (**И**, длительный режим).  
- Номинал — ближайший стандартный ряд вверх: 6; 10; 16; 20; 25; 32; 40; 50; 63; 80; 100; 125 А.

**Не реализовано в MVP (обязательно в предупреждении):**

- пусковые токи двигателей;  
- характеристики B / C / D;  
- `Iном ≤ Iдоп кабеля`;  
- условия отключения при КЗ (гл. 3.1 ПУЭ — **Требует проверки** пунктов).

### 4.4. Предупреждение при несоответствии

Формат: причина; фактические I, Iном, Iдоп (если S введено); рекомендация «проверить в модуле сечения / проекте».

## 6. Модуль «УЗО / дифавтомат»

### 6.1. Разделение понятий (справочно)

| Понятие | Единицы |
|---------|---------|
| Номинальный ток | А |
| IΔn | мА |
| Тип (AC / A / B и др.) | — |
| Дифавтомат vs УЗО + автомат | функции |

### 6.2. Логика MVP

**Справочный помощник**, не подбор «по названию комнаты».

Ввод: номинал автомата линии; тип нагрузки (AC-only / электроника / смешанная); зона (сухая / влажная — **только как подсказка**, не единственный критерий).

Вывод вариантов с пометкой **С**: типичные IΔn (10 / 30 мА) — **Требует проверки** по ПУЭ гл. 7.1 и СП 256.

Запрет: автоматически назначать 10 мА только за «ванную».

## 7. Модуль «Светодиодная лента»

### 7.1. Ветки

| Ветка | U | Расчёты |
|-------|---|---------|
| **Низковольтная** | 12 / 24 В DC | P, I, БП с kзап (П, 1,05–1,5), ΔU линии БП–лента |
| **Сетевая** | 220 В AC | отдельный текст: монтаж по инструкции производителя, автомат/УЗО, **не** DC-формула |

### 7.2. Формулы DC

- `P = L · Pуд`  
- `I = P / U`  
- `PБП ≥ P · kзап`  
- `ΔU = 2 · I · L · ρ / S` (% от U БП; лимит по умолчанию 3% **И**)

Сечение **не** выводить только из мощности БП без L и I.

## 9. Модуль «Кабель на заказ»

### 9.1. Формулы

```
Lбаза = Σ Li   (участки одной трассы, м)
Lбаза_всего = Lбаза × Nтрасс
Lс_запасом = Lбаза_всего × (1 + З% / 100)
Lзаказ = ceil(Lс_запасом)   // вверх до целого метра
Nбухт = ceil(Lзаказ / Lбухта)   // если Lбухта > 0
Lкуплено = Nбухт × Lбухта
Остаток = Lкуплено − Lзаказ
```

### 9.2. Запреты

- Не умножать длину на 2 для кабеля с жилами в одной оболочке.  
- Не прибавлять Lбухта к Lзаказ.  
- Не суммировать несколько трасс в строках без явного режима «несколько линий в одном заказе».

### 9.3. Валидация

| Ввод | Правило |
|------|---------|
| Длины | > 0 |
| Nтрасс | целое ≥ 1 |
| Запас | 0…50% (**П**) |
| Lбухта | пусто или > 0 |

## 10. Модуль «Смета»

- Позиции: наименование, ед., кол-во, цена (необязательна).  
- Позиция **без цены** не входит в денежную сумму и **не считается бесплатной** — отображать «без цены».  
- Итог: подытог → скидка % и фикс → надбавка → коэффициент сложности → налог → округление до рубля (**П**).  
- PDF — да; Excel — целевое расширение.  
- Офлайн-хранение, экспорт/импорт — по текущей архитектуре приложения.
