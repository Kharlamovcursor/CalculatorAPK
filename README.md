# HDLabs ЭлектроСмета

Нативное Android-приложение (Kotlin, Jetpack Compose) для расчёта стоимости электромонтажных работ, ведения прайса и формирования PDF-сметы. Работает офлайн; данные хранятся на устройстве.

## Сборка

**Удобная настройка с нуля (рекомендуется):** [docs/УДОБНАЯ_НАСТРОЙКА.md](docs/УДОБНАЯ_НАСТРОЙКА.md).  
Кратко только про сборку APK: [docs/BUILD_APK.md](docs/BUILD_APK.md).

1. Установите [Android Studio](https://developer.android.com/studio) (JDK 17).
2. Откройте папку `D:\Projects\CalculatorAPK`.
3. Дождитесь синхронизации Gradle и выполните **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

### Подпись release

```text
cp keystore.properties.example keystore.properties
```

Создайте keystore (`keytool -genkey ...`), укажите пути и пароли в `keystore.properties`. **Сохраните keystore и пароли в надёжном месте** — без них нельзя выпускать обновления поверх установленного APK.

## Установка APK на телефон

Передайте `app-release.apk` (Telegram, MAX, файлы). При первой установке Android попросит разрешить установку из этого источника.

## Обновления через GitHub

1. Создайте публичный репозиторий только для релизов (без секретов).
2. В приложении: **Настройки → О приложении** — укажите `GitHub owner` и `repo`.
3. Публикуйте релиз с файлом `.apk` и тегом вида `v1.0.1`.
4. В приложении нажмите **Проверить обновления** → **Скачать** → подтвердите установку.

Либо задайте значения при сборке в `app/build.gradle.kts` (`GITHUB_RELEASES_OWNER`, `GITHUB_RELEASES_REPO`).

## Резервная копия

**Настройки** → пароль → экспорт/импорт файла `.hdeb` (AES-GCM + PBKDF2). Пароль не сохраняется в приложении.

## Конфиденциальность

Имя и адрес клиента необязательны; данные не отправляются разработчику. При пересылке PDF ответственность за персональные данные несёт исполнитель.

## Минимальная версия

Android 9 (API 28).
